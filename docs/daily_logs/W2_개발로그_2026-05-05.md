## 🐛 W2 마무리 단계 트러블슈팅

### 🔧 문제 9: 폴더명이 숫자로 시작 → pytest import 실패

**증상**: `from games.07_speed_counter.src import question_gen` 불가 (W1 트러블슈팅 #3과 동일 원인).

**해결**: 테스트 폴더에 `conftest.py`를 두고 `src/`를 `sys.path`에 주입. 테스트 파일은 `from question_gen import ...` 식으로 직접 임포트.

```python
# tests/conftest.py
import os, sys
SRC_DIR = os.path.abspath(os.path.join(os.path.dirname(__file__), "..", "src"))
if SRC_DIR not in sys.path:
    sys.path.insert(0, SRC_DIR)
```

이 패턴은 W3 이후 모든 게임 테스트에 동일 적용 가능.

### 🔧 문제 10: `QuestionGenerator` 시드가 인스턴스 간 격리 안 됨

**증상**: `test_seed_reproducibility` 실패. 두 개의 `QuestionGenerator(seed=777)` 인스턴스가 서로 다른 수열을 생성.

**원인**: 생성자에서 `random.seed(seed)`를 호출 — 이는 전역 `random` 모듈의 상태를 초기화함. `a` 인스턴스와 `b` 인스턴스가 모두 동일한 전역 상태를 공유하므로, `a.next_question()` → 전역 상태 진행 → `b.next_question()`이 그 상태에서 이어받음.

**해결**: 인스턴스별 `random.Random(seed)` RNG 사용으로 변경 (`question_gen.py:67`).

```python
# Before
if seed is not None:
    random.seed(seed)         # 전역 random 오염

# After
self._rng = random.Random(seed)  # 인스턴스 격리
...
chosen = self._rng.choice(candidates)
```

부수 효과: 테스트가 게임 외 다른 코드의 random 상태에 영향을 주지 않음. **W3 이후 RNG가 필요한 모든 모듈에 동일 패턴 적용 권장.**
