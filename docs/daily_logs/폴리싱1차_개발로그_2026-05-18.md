### 4.4 Hand Spotlight (프라이버시)
사용자 요청: "사람 그림자도 닌자 모양의 실루엣으로 감추면 안되나?" → "개인 프라이버시도 있고. 손 모양만 노출하면 될 듯."

**구현**: `ui_renderer.apply_hand_spotlight(frame, hand_bbox)`
- 손 감지: 21개 landmark의 bbox → 대각선 × 1.6 = 반지름, 최소 80px
- 마스크: 외부=`SPOTLIGHT_DARKNESS(0.78)`, 원 내부=0, Gaussian blur 51 → 부드러운 경계
- 외부 영역: `SPOTLIGHT_TINT_BGR=(40,25,55)` 짙은 자주 (닌자 의상 톤)
- 손 미감지 시: 전체 0.85 darkness → "손 들기" 자연스럽게 유도
- PLAYING 페이즈만 적용 (선택/READY/GAME_OVER 화면은 안내문이 보여야 함)

지원 모듈:
- `finger_tracker.py`: `get_hand_bbox(landmarks, w, h)` 추가
- `game.py`: run 루프에서 `hand_bbox` 계산 → render(frame, tip_px, hand_bbox)에 전달

### 6.9 배경 채도/밝기 상향 (2026-05-19)

사용자 피드백 "바탕화면이 너무 어두움 — 채도 높여달라."

| 파라미터 | 이전 | 신규 |
|---|---:|---:|
| `BACKGROUND_BRIGHTNESS` | 0.25 | **0.85** |
| `BACKGROUND_SATURATION` | (없음) | **1.4** (신규) |

`load_background()` 변경:
```python
def load_background(path, screen_w, screen_h, brightness=1.0, saturation=1.0):
    # ... 크롭 + 리사이즈 ...
    if saturation != 1.0:
        hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV).astype(np.float32)
        hsv[..., 1] = np.clip(hsv[..., 1] * saturation, 0, 255)
        img = cv2.cvtColor(hsv.astype(np.uint8), cv2.COLOR_HSV2BGR)
    if brightness != 1.0:
        img = np.clip(img.astype(np.float32) * brightness, 0, 255).astype(np.uint8)
    return img
```

game.py의 load_background 호출에 saturation=theme.BACKGROUND_SATURATION 추가.
