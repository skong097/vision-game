## 🐛 트러블슈팅 기록

오늘 마주친 모든 문제와 해결 과정. 향후 W2 이후 비슷한 문제 발생 시 참고.

### 🔧 문제 1: `mediapipe.solutions` 속성 없음

**증상**: `AttributeError: module 'mediapipe' has no attribute 'solutions'`

**원인**: 신버전 MediaPipe (Tasks API) 가 설치됨. 레거시 API 미지원.

**해결**: `mediapipe==0.10.14` 로 다운그레이드

```bash
pip install mediapipe==0.10.14
```

`requirements.txt` 도 `mediapipe==0.10.14` 로 고정.

---

### 🔧 문제 2: 카메라 점유 잠금

**증상**: 비정상 종료 후 `❌ 카메라를 열 수 없습니다.`

**원인**: 이전 실행에서 카메라 release 보장 안 됨.

**해결책**: `game.py` 에 4가지 안전장치 추가
1. `try-except-finally` 블록 (run() 메서드)
2. `cleanup()` 메서드 (멱등성 보장)
3. `signal` 핸들러 (SIGINT, SIGTERM)
4. `atexit` 훅 (인터프리터 종료 시)

**임시 해결 명령**:
```bash
sudo fuser -k /dev/video0
pkill -f "games.06_rps_evolution"
```

---

### 🔧 문제 3: ImportError (직접 실행 시)

**증상**: `ImportError: attempted relative import with no known parent package`

**원인**: 폴더명이 `06_rps_evolution` 처럼 숫자로 시작 → Python 패키지명 규칙 위반.

**해결**: 모든 파일에 **상대/절대 임포트 자동 전환** 로직 추가

```python
try:
    from .judge import GameState  # 모듈 실행 시
except ImportError:
    sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
    from judge import GameState  # 직접 실행 시
```

이제 **두 방식 모두** 가능:
- `python -m games.06_rps_evolution.src.game` (권장)
- `python game.py` (직접 실행)

### 🔧 문제 4: NumPy 2.x 호환성 충돌

**증상**: `AttributeError: _ARRAY_API not found` / OpenCV가 NumPy 1.x로 컴파일됨

**원인**: NumPy 2.4.4 가 설치되어 있어 OpenCV와 충돌

**해결**:
```bash
pip install "numpy<2"
# 또는 정확히
pip install numpy==1.26.4
```

`requirements.txt` 의 numpy 버전도 `==1.26.4` 로 고정.

### 🔧 문제 5: OpenCV 화면 깨짐 (8.4 fps)

**증상**: cv2.imshow 화면이 작고 검게 표시, FPS 매우 낮음

**진단 과정**:
1. `camera_diagnostics.py` 실행 → 카메라 정상, X11 환경 확인
2. `opencv_render_test.py` 실행 → **해상도별 FPS 차이 발견**
   - 320x240, 640x480: 30.6 fps ✅
   - **1280x720: 10.2 fps** ❌

**원인**: 노트북 웹캠이 1280x720 을 30fps 로 지원하지 않음 (YUYV 압축 한계)

**해결**: 해상도 640x480 + 화면 표시만 확대

```python
# theme.py
SCREEN_WIDTH = 640
SCREEN_HEIGHT = 480
DISPLAY_SCALE = 1.5  # → 화면에는 960x720 으로 표시
```

### 🔧 문제 6: 한글 UI 렌더링 매우 느림

**증상**: 게임 실행 시 8 fps 정도

**원인**: PIL 텍스트 렌더링이 매 프레임마다 BGR↔RGB 변환을 10회 이상 반복

**해결**: **텍스트 배치 렌더링** 도입

```python
ui.begin_frame()           # 큐 초기화
ui.draw_text_korean(...)   # 큐에 추가 (그리지 않음)
ui.draw_text_korean(...)   # 큐에 추가
# ... (모든 텍스트 큐에 쌓기)
ui.flush_text(frame)       # 한 번에 PIL 변환 + 그리기
```

**결과**: BGR↔RGB 변환이 프레임당 **1회만** 발생 → FPS 대폭 개선

---

### 🔧 문제 7: 이모지 X 박스 표시

**증상**: `🎉`, `😢`, `✊` 등 이모지가 빈 사각형 (□) 또는 X 박스로 표시

**원인**: NanumGothic 폰트가 컬러 이모지 미지원 (PIL fallback 한계)

**해결**: 화면 표시 텍스트의 모든 이모지 제거. 대신 **색상 + 크기로 강조**.

콘솔 출력 (`print()`) 의 이모지는 그대로 유지 (터미널은 정상 표시).

---

### 🔧 문제 8: 화면 크기 동적 조절 요구

**증상**: 화면이 너무 작거나 큼

**해결**: 키보드 단축키로 동적 조절

| 키 | 동작 |
|----|------|
| **F** | 전체 화면 토글 |
| **+** / **=** | 확대 (0.25배씩, 최대 3.0) |
| **-** / **_** | 축소 (0.25배씩, 최소 0.5) |
| **0** | 기본 크기 (1.5배) 리셋 |
