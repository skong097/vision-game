## 친근 하트 도형 — 본 회차 신규 컴포넌트

`ui_renderer.draw_heart(center, scale, fill_color, outline_color)`:
- 좌상/우상 두 원 + 아래쪽 삼각형 합성 (`cv2.fillPoly`)
- 좌상단에 작은 흰 광택 점 (W5 친근 패턴 일관)
- scale 파라미터로 0.9~2.2x 크기 변경 가능

`draw_sync_heart(both_match, hold_progress, bonus)`:
- 둘 다 미매칭: 회색 빈 하트
- 둘 다 매칭: 핑크 채움, scale = 1.0 → 1.5 (유지 비율)
- 보너스(둘 다 ≥0.80): **레드 하트, scale ≥ 1.4**

→ 사용자에게 "지금 둘이 얼마나 맞춰가고 있는가"를 한 도형으로 직관 표현.

## 멀티 인물 처리 결정

기획서에서 "Face + Pose 멀티"라 했지만 V1은 단순화:

| 옵션 | 채택 여부 | 이유 |
|---|---|---|
| **Pose × 2 (좌/우 분할)** | V1 | 추가 의존성 X, 단순, 단위 테스트 가능 |
| YOLO로 사람 검출 → ROI Pose | V1 | YOLO + Pose × N → FPS 부담 큼 |
| MediaPipe Holistic | V1 | single-person, 멀티 인물 미지원 |
| Face Mesh + Pose 동시 | V1 | 한 사람만 해도 FPS 부담, 두 명은 더 큼 |

좌/우 ROI 추론은 각각 frame의 절반(320×480)이라 추론 속도가 다소 절약됨. `model_complexity=0` (FPS 우선) 채택.

**Trade-off 인지**: 두 사람이 화면 중앙 분할선을 넘어가면 잘못된 영역에 잡힘. 명확한 UI(분할선 + "사람 1/2" 라벨)로 행동 가이드.

## W8 회고

### 잘 된 것 

- **이전 학습 자동 적용 100%**: 트러블 0건. 7회차에 걸쳐 정리한 4개 규칙(`__init__.py` 삭제, lazy import 0, 모듈명 prefix, dual try/except, time_provider 주입)이 처음부터 적용.
- **하트 도형의 표현력**: scale·color·bonus 세 차원만으로 "지금 둘이 어떻게 맞춰가고 있는가"를 직관 전달.
- **W3·W4·W6 패턴의 결합**: W4 미션 회전, W6 pose 분류, W3 실시간 시뮬레이션이 한 게임에 자연스럽게 합쳐짐.
- **time_provider 주입의 가치 재확인**: sync_state 32 case 모두 deterministic — apply_sync의 누적·끊김 리셋·완료 트리거가 모두 시간 의존이지만 테스트 시간 제어로 깔끔히 검증.

### 어려웠던 것 

- **Pose × 2 FPS 미측정**: 좌/우 ROI가 절반 크기라 추론 속도 절약은 있지만, 두 인스턴스 직렬 호출이라 1.5~1.8배 정도 시간. `model_complexity=0`으로 보완했으나 정확도 trade-off 발생. 실기에서 확정.
- **분할선 넘어가는 케이스**: 두 사람이 중앙선을 넘으면 좌측 사람 landmark가 우측 ROI에 잡히거나, 한 사람이 양쪽에 잡힐 수 있음. 실기에서 안내 UI 강화 필요할 수 있음.
- **Face Mesh 미도입**: 기획서 "Face + Pose 멀티"보다 단순화. 발렌타인 시즌 마케팅 관점에선 "표정도 같이 맞춰야 한다"가 더 매력적일 수 있어 V2 후보.

### W9 이후 적용할 점 

1. **W6 pose 모듈 복사 → core 추출 시점이 명확**: W6·W8 두 게임에서 `pose_features`/`pose_classifier`가 동일. W9 시작 전 `core/vision/pose_features.py` 추출 1순위.
2. **친근 도형 헬퍼 core/ui 추출도 동일하게 시급**: W3~W8 모두 사용. `core/ui/friendly_shapes.py`로 옮기는 게 코드 중복 최소화.
3. **신규 트러블 0건이 2회 연속 (W7, W8)**: 학습 누적 효과가 안정화 단계. 다음 회차는 학습보단 core 추출 + 디자인 트랙(sprite 등) 진행하는 게 효율적.
4. **멀티 인물 한계 인지**: V1 분할 방식은 두 사람이 충분히 떨어져 있을 때만 작동. W10 AR 보물찾기는 한 사람만 추적이라 이 한계 영향 없음.
