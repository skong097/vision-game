## 📌 게임 개요

**Doby가 출제한 한국어 단어를 손짓·몸짓으로만 표현하는 게임.** 사용자가 단어를 표현하는 시간이 끝나면, **Claude API가 카메라 frame을 보고 어떻게 표현했는지 평가** (0~100점). 5라운드 / 4정답 이상 = 승리.

### 핵심 가치 (B2B2C)

| 이해관계자 | 효과 |
|---|---|
| **손님 (C)** | 몸으로 표현하는 재미. 친구·가족과 함께 보면 더 재밌음 (관전 가치) |
| **매장 (B)** | LLM이 매번 다른 코멘트 → 반복 플레이 동기 강함 |
| **플랫폼 (B)** | LLM 호출 비용은 라운드당 1회 → 손님당 5호출. 비용 통제 가능 |

### 핵심 특징

- **단어 풀 10개** (한국어): 강아지, 비행기, 농구, 노래, 잠자기, 책 읽기, 박수, 춤추기, 화남, 놀람
- **표현 시간 15초** (난이도별로 가변): 사용자가 손짓·포즈로 자유롭게 표현
- **LLM Vision 평가**: 마지막 frame 1장 → Claude API → 0~100점 + 짧은 코멘트
- **API 키 없으면 fallback**: rule-based 평가 (랜덤 50~70점 + "API 키 없음" 안내)
- **프롬프트 캐싱**: system 프롬프트(평가 가이드)는 캐싱해서 비용 절감

## 🧠 LLM 통합 설계

### silent_llm.py 인터페이스

```python
def evaluate_expression(
    word: str,
    image_bytes: bytes,
    *,
    api_key: str = None,
) -> EvalResult:
    """단어와 이미지로 표현 평가.

    api_key=None이고 ANTHROPIC_API_KEY 환경변수도 없으면 fallback.

    Returns:
        EvalResult(score: int 0~100, comment: str, used_api: bool)
    """
```

### 프롬프트 (system 캐싱)

```text
[system, cache_control=ephemeral]
당신은 손님이 어떤 단어를 손짓·몸짓으로 표현하는지 평가하는 심사위원이에요.
다음 단어 풀 중 하나가 출제됩니다:
강아지, 비행기, 농구, 노래, 잠자기, 책 읽기, 박수, 춤추기, 화남, 놀람.

각 단어를 잘 표현하는 핵심 동작:
- 강아지: 양손을 머리 위에 귀 모양 OR 네발 자세
- 비행기: 양팔을 좌우로 펴고 기울기
- 농구: 한 손을 위로 올려 슛 자세 OR 드리블 동작
... (생략)

평가 규칙:
- 핵심 동작 명확 + 자세 안정 → 80~100점
- 핵심 동작 일부 + 자세 흔들림 → 40~70점
- 단어와 무관 → 0~30점

응답 형식 (JSON):
{"score": 0~100, "comment": "20자 이내 짧은 코멘트"}

[user]
출제 단어: <word>
사용자 표현 이미지: [vision input]
```

### Fallback (API 키 없을 때)

- 점수: 50~70 사이 랜덤 (학습 가치는 없지만 게임은 진행)
- 코멘트: "API 키가 없어서 자세 평가는 생략했어요"
- used_api: False

### 비용 모델

- 라운드당 LLM 호출 1회 (마지막 frame 1장)
- system 프롬프트 캐싱 → 첫 호출 외에는 저렴
- 5라운드 = 5호출 = 매우 저렴 (Haiku/Sonnet 어느 쪽이든 게임당 몇 센트)
