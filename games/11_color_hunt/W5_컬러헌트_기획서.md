## 게임 개요

**"테이블 위에서 머스타드색 물건 3개를 찾아 카메라에 비추세요!"** 매장 안의 실제 사물을 카메라로 비추면 YOLO가 객체를 잡고, 우리가 만든 컬러 분류기가 그 객체의 대표 색을 식별. 미션 색과 일치하는 객체 N개를 시간 안에 모으면 승리.

### 핵심 가치 (B2B2C 관점)

| 이해관계자 | 효과 |
|---|---|
| **손님 (C)** | 매장을 능동적으로 둘러보는 행위 → 발견의 재미. 셀카·인증샷보다 매장 전체 활용 |
| **매장 (B)** | 자연스러운 메뉴/굿즈/인테리어 노출. 특정 색 미션이 시즌 메뉴 색과 매칭되면 직접 홍보 효과 |
| **플랫폼 (B)** | 매장별 객체·색 분포 데이터 자연 수집 → 카탈로그/매대 분석에 재사용 |

### 핵심 특징 — 세련된 8색 팔레트

기본 원색(순수 빨/파/녹) 대신, **매장·카페 미학에 어울리는 톤다운 팔레트**:

| # | 색 이름 | 키 톤 | 예시 |
|---|---------|------|------|
| 1 | 버건디 (burgundy) | 깊은 와인레드 | 와인병, 가죽소파, 빈티지 식기 |
| 2 | 테라코타 (terracotta) | 흙빛 주황-적색 | 화분, 라떼아트 컵, 벽돌 |
| 3 | 머스타드 (mustard) | 머스터드 옐로우 | 노란 책표지, 가구 쿠션, 시즌 메뉴 |
| 4 | 세이지 (sage) | 차분한 회녹색 | 식물, 도자기 그릇, 메뉴판 |
| 5 | 네이비 (navy) | 깊은 푸른색 | 의자 천, 유니폼, 데님 |
| 6 | 모브 (mauve) | 부드러운 자주-핑크 | 꽃, 음료 잔, 디저트 토핑 |
| 7 | 크림 (cream) | 따뜻한 오프화이트 | 라떼, 식기, 벽지 |
| 8 | 차콜 (charcoal) | 부드러운 검정 | 메뉴판, 가방, 머그 |

> **왜 세련된 팔레트인가**: 매장 사물의 실제 색상 분포는 순수 RGB 원색이 아닌 톤다운된 색이 다수. 분류기를 톤다운 영역에 맞추면 (1) 인식 신뢰도가 매장 환경과 자연히 정합되고, (2) 손님이 "찾아가는 색"이 매장 미학과 어긋나지 않아 광고감이 줄어듦.

## 게임 규칙

### 라운드 구조

```
READY  ── (SPACE) ──→  미션 출제: "버건디 색 물건 3개를 찾아주세요"
                            ↓
                   [60초 타이머 시작]
                            ↓
                   [카메라로 사물 비추기]
                            ↓
                   [YOLO 검출 → 객체 ROI → HSV 평균 → 컬러 분류]
                            ↓
                   [매칭 시: 카운트 +1, 효과음, 객체 박스 강조]
                            ↓
                   ┌─ 목표 N개 달성 → 라운드 승리
                   └─ 시간 초과 → 도전 실패
```

### 난이도

| 난이도 | 목표 개수 | 제한시간 | 미션 색 |
|--------|-----------|----------|---------|
| Easy   | 2개 | 90초 | 흔한 색 (크림/차콜) 위주 |
| Normal | 3개 | 60초 | 8색 균등 |
| Hard   | 4개 | 45초 | 톤 비슷한 색 위주 (모브 vs 버건디) — 분류 신뢰도 게이트 ≥0.75 |

### 검출·매칭 파이프라인

1. **YOLO**: COCO 80클래스 + (선택) 매장 특화 fine-tune. confidence ≥ 0.5만 채택
2. **ROI 추출**: 바운딩 박스 가운데 60% 영역 (배경 침범 최소화)
3. **대표 색 계산**: ROI HSV의 **중앙값(median)** — 평균은 noise·하이라이트에 민감
4. **컬러 분류**: `color_classifier.classify_color((h, s, v))` → (color_name, confidence)
5. **매칭 판정**: `color_name == mission_color` **and** `confidence ≥ 게이트`
6. **중복 방지**: 같은 객체(같은 트랙ID)가 5초 안에 다시 잡혀도 카운트 1번만
