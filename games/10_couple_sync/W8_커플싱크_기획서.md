## 게임 개요

**두 사람이 같은 포즈를 동시에 만들어 싱크를 맞추는 게임.** Doby가 미션 포즈 출제 → 두 사람이 동시에 같은 포즈를 일정 시간 유지하면 +점수 + 다음 미션. 60초 안에 목표 점수 도달하면 우승.

### 핵심 가치 (B2B2C)

| 이해관계자 | 효과 |
|---|---|
| **손님 (C)** | 둘이 함께하는 게임 — 발렌타인 시즌 데이트·친구·가족 활용 |
| **매장 (B)** | 두 명 손님이 같은 테이블에서 함께 즐김 → 체류 시간 ↑, 메뉴 더블 |
| **플랫폼 (B)** | 듀얼 Pose 데이터 — 매장 동선·인원수 분포 자연 수집 |

### 핵심 특징

- **포즈 5종 미션** (W6 그대로): T자/Y자/왼손위/오른손위/박수
- **두 사람 추적**: 화면 좌/우 분할 → 각 영역에서 Pose 추론 (V1)
- **싱크 유지 시간**: 둘 다 같은 미션 포즈를 **0.7초 이상 유지**하면 +점수 + 다음 미션
- **친근한 하트 UI**: 두 사람 사이에 하트 도형, 싱크 시 핑크/레드 → 깜빡임

## 게임 규칙

### 페이즈 (W3·W7 패턴 — 실시간 시뮬레이션)

```
DIFFICULTY_SELECT → READY ─(SPACE)─→ PLAYING (60초)
                                          ↓
                            WIN(점수≥목표) | TIMEOUT
                                          ↓
                                    GAME_OVER
```

게임 진행은 라운드 X 실시간 X — 미션 회전. **두 명 모두 매칭 + 임계 시간 유지 = 미션 완료 + 점수 + 다음 미션**.

### 점수 / 미션

- 미션 완료 시: **+20점** (W6 정답 100점보다 약간 낮음 — 60초 안에 여러 번)
- **싱크 보너스**: 두 사람의 individual similarity가 둘 다 0.8 이상이면 +5 보너스
- 목표 점수: easy 80 / normal 120 / hard 200
- 종료: 점수 ≥ 목표 → WIN, 60초 경과 → TIMEOUT(점수 미달)

### 미션 임계 / 유지 시간

| 난이도 | 매칭 임계 | 유지 시간 |
|---|---|---|
| Easy | 0.55 | 0.5초 |
| Normal | 0.65 | 0.7초 |
| Hard | 0.75 | 1.0초 |

매칭 임계 = 두 사람 각각의 `pose_similarity(mission, features)`. 두 값의 **min**이 임계 이상이면 "둘 다 매칭" — 한 명이라도 못 따라하면 진행 X.

### 멀티 인물 처리

V1은 **화면 좌/우 분할 + 각 영역에 별도 Pose 추론**:
1. 카메라 frame을 좌(0~width/2) / 우(width/2~width) 두 영역으로 자름
2. 각 영역에 MediaPipe Pose 1번씩 추론
3. 좌측 사람의 landmark + 우측 사람의 landmark → 각각 features 추출
4. sync_judge가 두 features로 매칭 판정

→ 추가 의존성 없음. FPS는 Pose 두 번이라 ~절반이지만 분할 영역이 작아져서 일부 보완.

## UI/UX

### 듀얼 박스 시각화

화면 좌/우 분할선 + 각 영역 상단에 "사람 1" / "사람 2" 라벨. Pose 잡힌 사람은 박스 핑크, 미잡힌 사람은 회색.

### 하트 도형

두 사람 사이(화면 중앙)에 큰 하트 도형. 싱크 상태에 따라:
- **둘 다 미잡힘**: 회색 빈 하트
- **한쪽만 매칭**: 노란 반쪽 하트
- **둘 다 매칭**: 핑크 채워진 하트 + 깜빡임
- **유지 시간 누적**: 하트 크기 점점 커짐 (0~1.0 비율로 scale 1.0 → 1.5)

### 화면 구성

```
┌─────────────────────────────────────────────────────────┐
│ 점수 60/120  미션: T자  남은 시간 32s                       │ HUD
├──────────────┬──────────────────────────────────────────┤
│              │                                            │
│   사람 1     │   (싱크 하트)   │     사람 2              │
│   (Pose 박스) │                   │     (Pose 박스)         │
│              │                                            │
├──────────────┴──────────────────────────────────────────┤
```
