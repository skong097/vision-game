## 게임 개요

**Doby가 보여주는 표정을 똑같이 따라하는 미러링 게임.** 5라운드 동안 4종 표정(웃음/슬픔/놀람/화남)을 출제하고, 손님이 정해진 시간 안에 같은 표정을 만들면 점수.

### 핵심 가치 (B2B2C 관점)

| 이해관계자 | 효과 |
|---|---|
| **손님 (C)** | 표정 따라하는 행위 자체가 즐겁고 셀카적 — SNS 공유 유도 |
| **매장 (B)** | "Doby와 인증샷" 자연스러운 동기 부여 → 매장 인지도/소셜 노출 |
| **플랫폼 (B)** | Face Mesh 데이터 학습용으로 표정 라벨 데이터 자연 수집 (개인정보 미저장 옵션) |

### 핵심 특징

- **4종 표정**: 웃음 (smile) / 슬픔 (sad) / 놀람 (surprised) / 화남 (angry)
- **landmark 비율 기반 분류**: 입 가로/세로 비율, 눈 개방률, 눈썹 위치 등
- **5라운드 60초 한 판**: 4정답 이상 = 승리, 3정답 이하 = 도전 부족
- **정확도 % 표시**: 단순 정답/오답이 아니라 표정 유사도 0~100%

## 게임 규칙

### 표정 4종 정의 (Face Mesh landmark 기반)

| 표정 | 핵심 특징 | 주요 landmark 비율 |
|---|---|---|
| **웃음 (smile)** | 입 양 끝 위로 + 입 가로로 늘어남 | mouth_aspect_ratio (가로/세로) ≥ 임계, 입꼬리 y < 입중심 y |
| **슬픔 (sad)** | 입 양 끝 아래로 + 눈썹 안쪽 위로 | 입꼬리 y > 입중심 y, 눈썹 안쪽이 바깥쪽보다 위 |
| **놀람 (surprised)** | 입 크게 벌림 + 눈 크게 뜸 + 눈썹 위로 | mouth_open_ratio ≥ 큰 임계, eye_open_ratio ≥ 임계 |
| **화남 (angry)** | 눈썹 안쪽 아래로 (찌푸림) + 입 좁게 | brow_furrow ≥ 임계, mouth_aspect_ratio < 임계 |

> 임계값은 W4 Step 2에서 **본인 얼굴로 캘리브레이션 모드 + 통계로 결정**. 첫 시도값은 일반적인 비율을 채택, 실기 테스트로 튜닝.

### 정확도 계산

각 라운드에서 출제 표정과 손님 표정을 비교해 0~100% 산출:

```python

    """
    target_expr: "smile" / "sad" / "surprised" / "angry"
    user_features: dict — landmark 비율들 (mouth_ratio, eye_open, brow_pos, ...)
    Returns: 0.0~1.0 (1.0 = 완벽 일치)
    """
    # 각 feature가 target의 기준 범위에 들어오는 정도를 평균
```

**판정 임계**:
- 정확도 ≥ 70% → 정답 (점수 100)
- 정확도 ≥ 40% → 부분 정답 (점수 50)
- 정확도 < 40% → 실패 (점수 0)

총점 = Σ(라운드 점수). 5라운드 만점 500점.

## 기술 설계

### 1) MediaPipe Face Mesh 도입

```python
mp_face_mesh = mp.solutions.face_mesh
face_mesh = mp_face_mesh.FaceMesh(
    max_num_faces=1,
    refine_landmarks=True,    # 입술/눈 정밀 landmark
    min_detection_confidence=0.7,
    min_tracking_confidence=0.5,
)
results = face_mesh.process(rgb)
# results.multi_face_landmarks[0].landmark[i] = (x, y, z) 정규화 좌표
```

**refine_landmarks=True** 시 478개 landmark (기본 468 + 입술/눈 10개).
