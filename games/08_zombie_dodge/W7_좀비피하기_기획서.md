## 📌 게임 개요

**위에서 떨어지는 좀비를 몸으로 피하는 액션 게임.** 60초 동안 좀비가 화면 위에서 떨어짐. 손님의 머리·어깨 박스(Pose로 추적)에 좀비가 닿으면 생명 -1. 시작 생명 3, 0이 되면 패배. 살아남거나 목표 점수 도달 시 승리.

### 핵심 가치 (B2B2C)

| 이해관계자 | 효과 |
|---|---|
| **손님 (C)** | 몸을 좌우로 움직이며 회피 — 활성 게임. 할로윈 분위기 |
| **매장 (B)** | 계절감 (할로윈 마케팅과 직결) — 시즌 메뉴와 매칭 가능 |
| **플랫폼 (B)** | 손님 좌우 활동 데이터 — 매장 동선 활용 분석 가능 |

### 핵심 특징

- **가상 좀비 5종** (V1): 색·크기 다른 둥근 도형 + 친근한 좀비 얼굴(눈·이빨)
- **Pose 머리·어깨 박스**로 회피 영역 정의 — 손가락이 아닌 **몸 전체**
- **60초 실시간**: 생명 3 / 목표 점수 200 (W3 패턴 차용)
- 좀비 회피 시 점수 +10, 충돌 시 -1 생명

### W3 카페 닌자 ↔ W7 좀비 피하기

W3와 가장 가까운 패턴 — 떨어지는 객체 + 충돌. 차이점:
- 검지 trail로 **베기** → 머리·어깨 박스로 **피하기**
- 메뉴(+점수) + 폭탄(-생명) → 좀비(닿으면 -생명, 화면 통과 시 +점수)
- 한 손 → 양 어깨 + 머리 박스

## 🎮 게임 규칙

### 페이즈 (W3 패턴)

```
DIFFICULTY_SELECT → READY ─(SPACE)─→ PLAYING (60초)
                                          ↓
                            WIN(점수≥목표) | LIVES_OUT(생명0) | TIMEOUT
                                          ↓
                                    GAME_OVER
```

### 난이도

| 난이도 | 목표 점수 | spawn 간격 | 좀비 속도 |
|---|---|---|---|
| Easy   | 100점 | 1.4s | 느림 |
| Normal | 200점 | 1.0s | 보통 |
| Hard   | 350점 | 0.7s | 빠름 + 가끔 가속 좀비 |

목표 점수는 W3와 비슷하게 — 60초 안에 회피만으로 도달 가능한 수준.

### 점수 / 생명

- 좀비가 회피 박스를 빠져나가 화면 밖으로 떨어짐 → **+10점**
- 좀비가 회피 박스(AABB)와 충돌 → **생명 -1**, 좀비 즉시 제거
- 생명 0 → 즉시 패배 (END_LIVES_OUT)
- 60초 경과 + 점수 미달 → 패배 (END_TIMEOUT)
- 점수 ≥ 목표 → 승리 (END_WIN)

### 회피 박스 정의 (Pose)

```python
def body_dodge_box(landmarks, frame_w, frame_h) -> Box:
    """
    landmarks → 회피 영역 박스 (AABB).
    - 머리: NOSE(0) ± head_radius
    - 몸통 좌우: LEFT_SHOULDER(11) ↔ RIGHT_SHOULDER(12)
    - 박스 상단 = NOSE.y - head_radius
    - 박스 하단 = SHOULDER y + body_height (어깨 너비의 1.3x 정도)
    """
```

좀비 박스(원형 충돌)와 AABB 충돌 판정 — 좀비 중심이 박스 안 또는 박스 가장자리에서 좀비 반지름 이내면 충돌.
